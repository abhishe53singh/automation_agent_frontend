Core conventions
----------------
- Authentication is JWT-based through the bearer token dependency.
  Protected endpoints require Authorization: Bearer <token>.
- Public endpoints: GET /, all /auth/* routes, GET /files/supported-types.
- JSON is the default content type. Some endpoints use form-urlencoded or
  multipart/form-data (auth login, file upload), and chat streaming uses
  text/event-stream.
- Ownership and project access are enforced by dependencies; unauthorized access
  is typically rejected as 404 instead of exposing entity existence.
- Models and schemas live in app/schemas/*.py; service logic lives in
  app/services/*.py; SQLAlchemy models live in app/models/*.py.

Notes for clients
-----------------
- Always use the bearer token returned by /auth/login or /auth/google.
- Project-scoped resources are usually filtered by project_id; membership is enforced by dependencies.
- Knowledge and file routes are the primary APIs for RAG and ingestion workflows.
- The app exposes a live OpenAPI schema at /openapi.json, Swagger at /docs, and Redoc at /redoc.
