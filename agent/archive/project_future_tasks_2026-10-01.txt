Tooling note: this terminal harness KILLS long foreground commands.
Run them detached and poll the log file, e.g.
  Start-Process cmd -ArgumentList '/c','npm run build > build.log 2>&1 & echo EXIT=%ERRORLEVEL% >> build.log' -WindowStyle Hidden
Always append an explicit EXIT=%ERRORLEVEL% marker — without it a
stale log from the previous run reads as success.
