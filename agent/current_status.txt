## Environment notes
- The terminal harness kills long foreground processes. Run detached and poll a log:
  Windows: Start-Process cmd -ArgumentList '/c','npm run build > out.log 2>&1' -WindowStyle Hidden
  Budget 2-5 min for build/lint on this machine; first compile of a route ~20 s.
- Backend: cd ../backend && venv\Scripts\python.exe -m uvicorn main:app --port 8000
- verify:bff needs `npm run build && npm run start -- -p 3100`; cookies are Secure in
  production so plain-HTTP clients drop them (scripts drive an explicit cookie jar).
- Editor caveat: chunked insert_line on long files can orphan blocks; re-read the seam.
- Known upstream quirks: see K18.
